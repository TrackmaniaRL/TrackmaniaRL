# TrackmaniaRL branding assets

Use the name **TrackmaniaRL** for the current Python library.

| Asset | Purpose |
| --- | --- |
| [Wide logo](assets/trackmaniarl-logo.png) | README and documentation |
| [Square avatar](assets/trackmaniarl-avatar-square.png) | GitHub organization avatar |
| [Social preview](assets/trackmaniarl-social-preview.jpg) | Repository link cards, 2:1 aspect ratio |

The square avatar and social preview were generated with OpenAI image generation
using the existing wide logo as the visual reference. The palette is near-black,
ivory and lime. The preview is illustrative branding, not a training result.

Uploading a social preview in GitHub's repository settings is separate from
committing this file. Existing shared links may keep a cached preview until the
sharing service refreshes it.
